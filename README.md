# Vennila Accessories Admin Panel

Vite + React Web Dashboard for managing products, categories, sub-filters, and technicians for Vennila Accessories.

## Tech Stack
- **Framework**: React 19 (Vite)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Animations**: Framer Motion
- **HTTP Client**: Axios

## Development
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```
